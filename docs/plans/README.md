# Plans Directory
Last updated: 2026-02-15

Execution plans are first-class artifacts for multi-session work.

## Conventions

- Active plans live in `docs/plans/` and use `YYYY-MM-DD-slug.md` filenames.
- Completed plans move to `docs/plans/completed/`.
- Plans are the source of truth for long-running or multi-step implementation work.

## Workflow

1. Create a plan before starting complex work.
2. Update status and decision log as work progresses.
3. Move the file to `completed/` when acceptance criteria and verification are done.
